# Django Blueprint documentation website

Docusaurus site for Django Blueprint, deployed to GitHub Pages at
https://dwarsbit.github.io/django-blueprint/ by `.github/workflows/website.yml`.

Shares its visual identity (palette, typography, hero and feature-card
components) with the Django Headless and Django Content Studio docs sites.

## Local development

```bash
npm install
npm start        # dev server with hot reload
npm run build    # production build to build/
npm run serve    # serve the production build
```

Docs content lives in `docs/`; the sidebar is autogenerated from the folder
structure. The landing page is a React page in `src/pages/index.tsx`; docs
serve under `/docs`.
