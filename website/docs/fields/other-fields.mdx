# HTML, choices and tags

## HTMLField

A semantic `TextField` for HTML content. It stores text and does not
sanitize it — run content through your sanitization pipeline before
rendering.

```python
from blueprint.fields import HTMLField


class Article(models.Model):
    body = HTMLField()
```

## MultipleChoiceField

A JSON array field with a fixed set of allowed values. Options can be passed
as a mapping or an iterable of pairs; values outside the options are rejected
by the field's validator.

```python
from blueprint.fields import MultipleChoiceField


class Page(models.Model):
    sections = MultipleChoiceField(
        options={"hero": "Hero", "grid": "Grid", "cta": "Call to action"}
    )


page = Page(sections=["hero", "grid"])  # valid
page = Page(sections=["hero", "oops"])  # ValidationError
```

Defaults to an empty list and `blank=True`. The options are part of the
field's serialized form, so changing them produces a migration.

## TagField

A JSON array field for tags. Any string is a valid tag — the field has no
opinion on their shape. The only thing it does is trim surrounding
whitespace on save.

```python
from blueprint.fields import TagField


class Article(models.Model):
    tags = TagField()


article = Article(tags=["Django", " web dev ", "Django"])
article.save()
article.tags  # ["Django", "web dev", "Django"]
```

Defaults to an empty list and `blank=True`.

## HashTagField

A JSON array field for hashtags, built on `TagField`. Values are normalized
to hashtag form on save: lowercased, all whitespace and `#` signs removed,
duplicates dropped and empty results discarded.

```python
from blueprint.fields import HashTagField


class Article(models.Model):
    hashtags = HashTagField()


article = Article(hashtags=["#DjangoCon", "  New York ", "djangocon"])
article.save()
article.hashtags  # ["djangocon", "newyork"]
```

Defaults to an empty list and `blank=True`.
